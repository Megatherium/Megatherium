- [**gore**](https://github.com/Megatherium/gore) — Self-hosted GitHub Releases APT/RPM repository gateway distributed as a single static binary or Docker image *(Go)*
- [**blunderbust**](https://github.com/Megatherium/blunderbust) — TUI launcher and tmux session manager for AI coding harnesses with Beads/Dolt issue tracking *(Go, Bubble Tea)*
- [**troveler**](https://github.com/Megatherium/troveler) — Offline-first terminal TUI for browsing, searching, and installing CLI tools from Terminal Trove *(Go, Bubble Tea)*
